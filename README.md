# SoftwareSwitch

**SoftwareSwitch** ist ein Windows-Tool, mit dem du alle deine Daten – Dokumente, Bilder, installierte Programme und mehr – bequem und sicher über das lokale Netzwerk von deinem alten auf deinen neuen PC übertragen kannst. Kein USB-Stick, keine Cloud, keine Kabel nötig.

Dieses Repository enthält ausschließlich die veröffentlichten Installationspakete – **keinen Quellcode**.

## Download

- **[SoftwareSwitch herunterladen](https://github.com/Airvyn1/SoftwareSwitch-Releases/releases/latest/download/SoftwareSwitch-win-Setup.exe)** (empfohlen, mit Installer)
- [Portable Version](https://github.com/Airvyn1/SoftwareSwitch-Releases/releases/latest/download/SoftwareSwitch-win-Portable.zip)

## Automatische Updates

SoftwareSwitch prüft beim Programmstart selbstständig, ob eine neue Version verfügbar ist, und fragt vor der Installation nach – ein manueller Download ist danach in der Regel nicht mehr nötig.
